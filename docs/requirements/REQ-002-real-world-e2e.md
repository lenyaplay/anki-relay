# REQ-002: Проверка в реальном мире (AnkiWeb + Claude)

- **Статус:** draft
- **Дата:** 2026-10-05
- **Связано:** ROADMAP → «Этап 2»; REQ-001

## Зачем

Автотесты покрывают код против фейка AnkiWeb и локального `anki.syncserver`, но не
против настоящего AnkiWeb (ограничения частоты, реальные ошибки, большие коллекции)
и не против настоящего Claude (как он пользуется инструментами, размер ответов,
поведение коннектора, OAuth-клиент claude.ai). Этот REQ — чек-лист ручной проверки,
результаты которой превращаются в новые REQ.

## Что меняется

Код — нет. Результат — заполненный чек-лист ниже и новые REQ по находкам.

## Влияние на данные пользователей

Проверка идёт на **тестовом** аккаунте AnkiWeb (не на основной коллекции) до тех
пор, пока все пункты не пройдены.

## Чек-лист

Подготовка
- [ ] Тестовый аккаунт AnkiWeb с коллекцией (~200 заметок, несколько колод, медиа).
- [ ] VPS, поддомен, `.env`, `docker compose up -d` в режиме `caddy`; сертификат получен.
- [ ] То же в режиме своего nginx по `deploy/nginx.conf.example` (на втором хосте или после переключения).

Подключение
- [ ] claude.ai → Add custom connector → Connect → страница входа (RU и EN, тёмная тема на телефоне).
- [ ] Неверный пароль → понятная ошибка; адрес не из списка → та же ошибка, в логах AnkiWeb не вызывается.
- [ ] Успешный вход → коннектор активен в веб, десктопе и мобильном приложении.

Синхронизация
- [ ] Первый вызов: полное скачивание, время, медиа докачиваются в фоне.
- [ ] «Добавь 50 карточек …» → одна отправка (по логам), карточки на телефоне после синхронизации.
- [ ] Изменение на телефоне → видно через `find_notes` спустя `SYNC_PULL_INTERVAL`.
- [ ] `add_media` по URL и base64 → картинка и звук на телефоне.
- [ ] Смена схемы через Claude (dry run → подтверждение) → полная выгрузка → на телефоне «Скачать с AnkiWeb».
- [ ] Смена схемы в Anki Desktop → сообщение сервера, `sync(force_download=true)` по указанию.
- [ ] `docker compose restart` посреди серии изменений → изменения не потеряны.

Безопасность и отзыв
- [ ] Удалить email из `ALLOWED_EMAILS`, перезапустить → Claude получает 401, переподключение невозможно.
- [ ] Удалить `data/oauth.json` → все разлогинены, повторный вход работает.
- [ ] `grep` по логам и `data/` на пароль тестового аккаунта → пусто.
